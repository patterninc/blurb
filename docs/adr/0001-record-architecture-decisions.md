# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-06

## Context

Load-bearing choices in this repo lived only in PR history and people's heads, so contributors and
agents could "simplify" them away.

## Decision

Record each such choice as a numbered ADR in `docs/adr/`, from `0000-template.md`. An accepted ADR
is not edited; a reversal is a new ADR that supersedes it.

## Consequences

Reviewers and agents cite an ADR number instead of relitigating a decision. AGENTS.md links here.
